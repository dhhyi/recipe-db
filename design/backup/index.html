Recipe DB Backup

Private backups for a personally operated recipe database.

What this tool does

Recipe DB Backup uses rclone to store recipe database backups in the operator's Google Drive and retrieve them for recovery. It is a personal administration tool, not a public backup service. Visitors to this page are not asked to sign in or grant access to Google Drive.

Limited Google Drive access

The operator authorizes a dedicated desktop OAuth client using the drive.file permission. This allows the tool to create and manage its own backup files and folders, rather than request access to all files in the account. Backup folders are kept private and are not served by this website.

Privacy and support

Read the privacy policy for data handling, retention, and revocation details.

Source code and technical support are available in the Recipe DB repository. Never post backup contents, account details, or credentials in public issues.
