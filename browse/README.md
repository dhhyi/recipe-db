# Frontend

Implemented using [Go](https://go.dev/), [templ](https://templ.guide/) for type-safe HTML templates and [htmx](https://htmx.org/) for server-driven interactivity without a custom client-side controller.

The frontend pages are annotated with HTML microdata for better SEO and structured data support. (i.e. using [Recipe](https://schema.org/Recipe), [AggregateRating](https://schema.org/AggregateRating), ...)
